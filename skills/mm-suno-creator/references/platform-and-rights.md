# Platform behavior and rights

Suno model names, controls, input limits, and UI behavior change. Read the user's visible interface or current official documentation before asserting a current limit. The lint script accepts `--max-chars` so a verified limit can be supplied at runtime; its default is a conservative project budget, not an official platform claim.

Translate named references into attributes such as tempo, groove, instrumentation, vocal register, arrangement density, harmonic color, production era, and emotional arc. Do not request a recognizable melody, lyric passage, voice clone, or close imitation of a living artist's distinctive style.

Do not operate accounts, purchase credits, publish tracks, or accept terms unless the user separately authorizes the external action.
